IMS Backup - Privacy policy

Last updated: 14 October 2026

What this app is

IMS Backup is a private tool run by its owner on the owner's own server. It uploads encrypted backup files to the owner's own Google Drive. It is not offered to other people.

What it accesses

The app asks only for the Google Drive scope "drive.file". With this scope it can see and manage only the files and folders that the app itself created in Google Drive. It cannot see any other file in the Drive.

What it does with the data

  • The backup files are encrypted before they leave the server.
  • They are stored only in the owner's Google Drive. They are not sent to, shared with, or sold to anyone else.
  • The app does not collect, store or use any other personal information from Google.
  • The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. The backup files can be deleted from Google Drive by the owner at any time.
